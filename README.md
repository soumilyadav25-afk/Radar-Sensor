# Radar-Sensor
I built a rotating distance-detection system using an ESP32, distance sensor, servo motor, and display screen. The servo rotates the sensor to detect objects, while the ESP32 processes the measurements and displays the distances in real time. I used Arduino IDE to program the system and troubleshoot issues.
